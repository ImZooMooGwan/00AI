# 00AI REPLY — 의회·감사 요구자료 자동작성
2026-11-01 MVP v0.1 기능검증 결과 및 개발 명세

## 목적
의회/감사/중앙부처 요구문과 근거자료에서 자료를 찾아, 출처가 포함된 제출 답변 초안을 만들고 정형 집행률 오류를 검증한다.

## MVP 기능(로컬 검증)
- CSV/TSV/XLSX/HWPX/TXT/MD 파일/폴더 업로드
- 파일명, 시트 및 실제 행 번호, 문단 위치 표시
- 요구문 키워드 검색과 출처 표시
- 같은 행의 예산액/집행액/집행률 검증
- 담당자가 수정 가능한 답변서 초안
- DOCX/TXT 내보내기 및 인쇄
- 파일당 12MB/전체 50MB/최대 40개
- 사용자의 브라우저에서만 분석하며 서버로 원문을 전송하지 않음

## 시험 결과
가상 CSV 3행 중 집행률 88% (95%가 정답) 오류 탐지; XLSX 테스트에서 기재 70%, 재계산 80% 불일치 탐지; HWPX 문단 2건 추출; 생성 DOCX 무결성 검사 통과; Chrome 데스크톱/모바일 렌더링 및 JS 예외 없음.

## 제약
정형 열 기반 집행률 검증만 구현. PDF, 기존 HWP, OCR, 합계/증감률, 온나라 연결, AI 의미 분석, 권한/감사로그 미구현. 브라우저의 ZIP deflate-raw 압축해제 지원 필요. 공개 베타에 대외비나 개인정보 포함 원문 업로드 금지.

## 개발 로드맵
1. 문서 파서 고도화 + 금액 단위 정규화 + 시트 행 좌표 및 교차 검증
2. 요구항목별 근거 지정, 출처 충돌 비교, 문서 템플릿
3. 폐쇄망 온프레미스 검색 인덱스와 검증형 AI 연결
4. 역할별 권한, 감사로그, 정식 보안 심사, 00AI DOCS 연계

## 수용 기준 (목표)
20건 검증 시나리오 출처 정확도 95% 이상; 정의된 집행률 오류 10건 탐지 재현율 100%; 수작업 초안 대비 작업 시간 50% 절감 검증.

실행용 HTML은 개발 환경 산출물로 분리 보관. 이 파일만으로 서비스 배포가 이루어진 것은 아닙니다.

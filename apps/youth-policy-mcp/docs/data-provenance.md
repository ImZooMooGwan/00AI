# 데이터 출처와 근거

## 우선순위

1. 개별 사업의 공식 신청 공고
2. 온통청년 공식 정책 레코드
3. 국가법령정보센터의 확인된 법령·조례 원문
4. 기타 공식 기관 페이지

출처가 충돌하면 조용히 덮어쓰지 않고 `conflict_note`에 기록합니다. 현재 온통청년 레코드만 확인된 필드는 그 사실을 그대로 표시합니다.

## 수집 기록

각 정책은 원천 시스템·원천 정책 ID·공식 URL·수집시각·원문 해시를 갖습니다. 필드별 evidence는 기준일과 확인일을 분리합니다. API 키가 포함된 요청 URL이나 원시 오류는 저장하지 않습니다.

## 법령 연결

원천이 명시한 법령명과 URL은 높은 신뢰도로 저장할 수 있습니다. URL·ID·조문이 불충분하면 낮은 신뢰도와 `manual_review`로 보존합니다. 정책명에서 법적 근거를 추정해 생성하지 않습니다.

## 인용

권장 형식은 `원천기관, '정책명', 원천 정책 ID, 기준일, 확인일, 공식 URL`입니다. `get_policy_evidence`가 필드별 인용 문자열을 제공합니다.

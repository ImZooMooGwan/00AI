00Upscaling 사용 안내

  1. 이미지를 끌어다 놓거나 파일 추가 또는 Ctrl+V로 넣습니다.
  2. 간편 모드에서 사진 / 문서·표 / 로고·아이콘을 고릅니다.
  3. ×2, ×3, ×4 배율을 선택한 뒤 변환 시작을 누릅니다.
  4. 미리보기에서 마우스 휠로 확대/축소하고 드래그로 이동합니다. 결과가 있으면 비교선을 좌우로 움직여 전후를 확인할 수 있습니다.
  5. 저장 형식을 고르고 현재 결과 저장을 누릅니다. 큐 전체 저장은 변환되지 않은 항목까지 순서대로 처리합니다.

보안: 외부 서버, CDN, API, 웹폰트를 사용하지 않습니다. 이미지는 이 브라우저 탭의 메모리에서만 처리됩니다.

자가 검증: F12 → 네트워크 탭 → 페이지 새로고침 및 변환 → 외부 요청 0건 확인

주의: 브라우저/PC의 실제 메모리 한계가 16,384px·268MP보다 낮을 수 있습니다. 매우 큰 출력은 배율을 낮추어 처리하십시오.

# 제품 요구사항 요약

## 사용자
- 관리자: 사용자 역할, 시스템 설정, 전 기능 접근
- 채용담당자: 지원자 생성, 지원건 변경, 파일/평가/면접 관리
- 평가위원: 권한이 있는 지원건의 이력서·면접 평가 조회 및 평가 입력

## 업무 흐름
지원자 생성 → 지원건 생성 → 서류접수 → 1차면접 → 최종면접 → 최종합격 또는 불합격. 예외적으로 단계 이동/불합격 복원이 가능하며 모든 전이는 이벤트로 남긴다.

## 개인정보
지원자 이메일, 연락처, 이력서 및 평가 내용은 제한된 업무 목적에 필요한 범위로만 저장한다. 이메일 주소는 지원건 생성 시 저장한 주소로 발송되며, 발송 예약의 수신주소와 템플릿 버전을 스냅샷으로 고정한다. 실제 보존기간은 조직 정책에 따라 배포 전에 설정해야 한다.

## 우선순위
1. 저장되는 파이프라인 및 오류 복구
2. 예약 이메일의 취소 가능성, 10분보다 이른 발송 방지
3. 비공개 이력서 관리와 최소 권한
4. AI 지원은 별도 동의·운영정책 확인 후 활성화

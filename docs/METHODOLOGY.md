# Methodology

Y-HUB의 실시간은 초 단위 갱신을 뜻하지 않는다. 원천별 갱신주기에 따라 지속 확인하고 변화가 감지되면 이벤트를 생성한다는 운영 정의를 사용한다.

`announced_at`, `effective_at`, `source_updated_at`, `detected_at`, `reviewed_at`, `published_at`, `fetched_at`을 구분한다. 정책 효과나 인과관계는 데이터만으로 단정하지 않는다.

AI는 공식 문서 구조화, 중복 후보 탐지, 변경요약, 검색조건 변환을 돕는다. 존재하지 않는 정책·수치를 만들거나 지원 가능 여부·법률 해석을 확정할 수 없다.

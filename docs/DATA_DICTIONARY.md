# Data Dictionary

| 필드 | 의미 |
|---|---|
| `id` | 안정적인 Y-HUB 정책 ID |
| `programId` | 집행 프로그램 ID |
| `roundId` | 연도·회차 ID |
| `status` | open, upcoming, rolling, closed, unknown |
| `verificationStatus` | machine_detected, review_required, partially_verified, verified |
| `firstObservedAt` | 최초 관측일 |
| `lastObservedAt` | 마지막 관측일 |
| `sourceId` | 공식 원천 참조 ID |
| `detectedAt` | 변경 감지 시점 |
| `effectiveAt` | 실제 시행 시점 |
| `impact` | critical, high, medium, low, informational |

# Decisions

1. 기존 Vinext·Cloudflare Worker 구조를 보존했다.
2. 초기 운영비를 줄이기 위해 데이터베이스보다 검증 스냅샷을 먼저 제공한다.
3. 임의 통계값을 넣지 않고 API 키가 없으면 지표 연결 상태를 표시한다.
4. 3D 정책 우주 대신 접근 가능한 2D SVG 관계망을 기본으로 했다.
5. 전국 지도는 MVP에서 정확한 지리경계보다 키보드로 탐색 가능한 17개 시도 카토그램을 사용한다.
6. 관리자 쓰기 기능은 인증·권한·감사로그 전에는 읽기 전용으로 둔다.
7. 변동 가능성이 큰 정책은 `partially_verified` 또는 `review_required`로 표시한다.

# 00AI Gov Docs 단계별 개발·검수 보고 (2026-10-28)
## 운영 배포
- URL: https://docs.00ai.kr/
- Worker: 00ai-gov-docs (Cloudflare PUT HTTP 200)
- 변경 소스: gov-docs/worker.js 및 gov-docs/v3-ui.html
- 기존 Brevo·HASA·SESSION_SECRET, D1 binding 보존

## 1차: 보안·편집 안정성
- 완료: 문서 소유자 및 명시적 공유 사용자만 문서 목록·본문 조회 가능
- 완료: save, rename, comments, files, version list API에 접근권한 검증 추가
- 완료: 공유자 editor/viewer 지정·초대 API 및 화면
- 완료: 구형 weekly API /api/doc, /api/update 410 비활성화
- 완료: 저장 때마다 버전 스냅샷 D1 기록 및 선택 복원 API
- 완료: viewer UI 읽기 전용 표시
- 미완료: Tiptap/ProseMirror 구조화 편집기, 전문 보안진단·서버 측 HTML sanitizer
## 2차: 실시간 협업
- 완료: 기존 3.5초 polling 및 revision conflict detection 유지
- 미완료: Yjs CRDT/Cloudflare Durable Objects, 실시간 공동 커서, 문단별 제안 승인/거절
## 3차: 문서 호환성
- 기존 기초 기능 유지: DOCX, 텍스트 PDF, HWPX 추출과 AI 재구성
- 미완료: 바이너리 HWP 정밀 변환, 이미지/표 원형 복원, R2 원본 보관(계정 활성화 필요), 정식 DOCX/HWPX 출력
## 4차: 문서 관리
- 완료: 문서 목록을 소유자/초대된 문서로 필터링
- 기존 유지: 검색, 템플릿, 문서 제목
- 미완료: 노션식 블록 데이터베이스, 폴더 계층, 팀 워크스페이스, 전문 검색
## 5차: 행정 AI
- 완료: 기준값 대비 달성률·증감액·증감률 결정론적 계산 API 및 화면
- 기존 유지: HASA 문서 재구성, 요약, 문체 교정, 숫자 검토
- 미완료: 다중 부서 자동 취합 파이프라인, 출처별 신뢰도·근거 추적, 자동 승인 워크플로

## 최종 검수
- Cloudflare 배포 API 성공
- GitHub HTML/Worker 최신 번들 일치: 확인
- 프런트 스크립트 정적 문법: 통과
- 문서 접근·초대·버전 복원 경로 코드 검사: 통과
- Cloudflare 비밀값 구성: 유지 확인
- 실제 2인 브라우저 동시 접속·파일 업로드·침투 시험: 미진행
- 원본 문서 사용은 보안 및 협업 품질 시험 완료 전 금지

## 판정
1~5차의 일부 범위만 개발·배포 완료. 5개 단계 전체 완료 아님.

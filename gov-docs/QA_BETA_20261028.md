# 00AI Gov Docs — 베타테스트 운영 준비 및 검수보고
일자: 2026-10-28

## 이번 개발/배포
- 베타 의견 접수 API POST /api/v2/feedback: 오류·사용성·기능제안·기타, 5자 이상, 3,000자 이하; 작성자 식별값 및 문서 ID 기록
- 베타 의견 작성 UI: 왼쪽 '오류·개선 의견 제출', 오른쪽 '의견' 패널
- 문서 JSON 백업 API GET /api/v2/export-backup?id=...: 현재 본문과 최대 50개 버전; 문서 접근권한 검증
- 브라우저 백업 파일 다운로드 기능: 현재 문서 백업
- D1 테이블 beta_feedback 신규 생성
- 이전 기능 유지: 이메일 인증, 문서별 ACL, 문서 관리, 8종 템플릿, AI 분석, 댓글, 버전 관리
- Cloudflare Worker PUT HTTP 200, HTML 소스/Worker 번들 일치 확인

## 베타 참여자에게 제공할 테스트 시나리오
1. @korea.kr OTP 이메일 인증, 닉네임 등록
2. 새 문서 생성 → 제목 변경 → 작성 및 자동저장 → 새로고침 후 데이터 확인
3. 공무원 취합 샘플 8종 중 2개 생성 및 표 편집
4. 문서 소유자가 다른 참여자 이메일 초대(editor/viewer)
5. 편집자 저장 및 조회자 저장 차단을 각각 확인
6. 댓글 작성, 검토 요청 → 승인 → 최종 확정 후 편집 잠금 확인
7. 문서 버전 목록 및 과거 버전 복원 (초안에서만)
8. DOCX, HWPX, 텍스트 PDF 파일 추출 및 AI 재구성 품질 확인 (반드시 공개/더미 파일)
9. 문서 JSON 백업 다운로드와 파일 내용 확인
10. 베타 의견 제출(재현 단계 포함)
11. 모바일/행정망/크롬/엣지 화면의 표시 및 외부 CDN 차단 여부 확인
12. 두 사용자가 동시에 한 문서를 편집할 때 409 충돌 안내 확인 (현재 실시간 CRDT는 아님)

## 베타 승인 전 차단 조건
- 실제 개인정보·비공개 행정자료 입력 금지
- 권한 없는 문서 조회/수정 차단을 독립 계정 2개로 시험
- 동시수정 중 데이터 소실·충돌 처리 시험
- 파일 변환 결과의 표·숫자 원문 대조
- AI가 제안한 숫자·날짜의 출처 확인 및 수동 승인
- 브라우저 콘솔 오류 및 네트워크 오류 확인
- 문서 보존·삭제·유출 대응 절차 수립

## 미완료·운영상 제한
- Yjs/Tiptap 실시간 공동 편집, 조직 전역 관리자·SSO/SCIM, R2 원본 첨부 저장, 정밀 HWP 변환, OCR, 원본에 충실한 DOCX/HWPX/PDF 내보내기 미구현
- feedback 데이터는 D1에 보관되며 현재 운영 UI에 전체 제보 열람/분류 관리자 화면이 없음
- 백업은 개인 다운로드 기능으로 서버 자동 백업/DR 복구가 아님
- 보안 침투 시험, 이용자 E2E, 파일 변환 품질 보증 미수행
- 베타에 참여할 수 있는 사용자는 현재 @korea.kr 인증 가능 사용자이며, 별도 베타 명단 화이트리스트는 미구현
- 공개정보 또는 합성 데이터를 이용한 **통제된 기능 베타테스트**만 권장. 행정기관 정식 운영 승인 또는 보안 인증과 동일하지 않음

## 검수 근거
- Worker 배포 API HTTP 200
- 프런트 내장 JS 구문 분석 PASS
- Cloudflare SECRET names BREVO_API_KEY/HASA_API_KEY/SESSION_SECRET 존재
- D1 beta_feedback 테이블 존재
- 파일 기준 UI-Worker inline 번들 일치 PASS
- 실제 브라우저 E2E 및 발송·수신까지 자동 확인 불가

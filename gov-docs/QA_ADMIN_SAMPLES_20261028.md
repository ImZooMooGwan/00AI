# 00AI Gov Docs 공무원 취합문서 및 관리자 기능 검수 보고

기준일: 2026-10-28. 배포: https://docs.00ai.kr/

## 이번 배포 기능
### 공무원 취합문서 샘플 8종
1. 부서별 주간업무 취합
2. 의회 요구자료 취합
3. 예산 집행현황 취합
4. 성과지표 및 실적 취합
5. 회의 결과·후속조치 취합
6. 사업 추진상황 취합
7. 감사 요구자료 취합
8. 부서별 현황조사 취합

샘플 메뉴를 선택하면 새 문서가 생성되고 기본 제목·표·목차가 입력된다. 실사용 이전에 조직에 맞는 항목을 변경한다. 샘플에는 가상 항목만 포함한다.

### 관리 기능 (문서 소유자 범위)
- 선택 문서 제목, 상태 및 버전 조회
- 초대 참여자 이메일/역할 조회
- 소유자에 의한 참여자 권한 회수
- 문서별 감사 이력(수정·생성·상태변경 등) 100건 조회
- 내가 소유한 문서 요약 API
- 기존 초대 API(editor/viewer) 연계
- 서버 측 소유자 권한 검증. 일반 사용자는 타인 소유 문서 관리자 API 접근 불가

## 기술 구현
- Cloudflare Workers: `gov-docs/worker.js`
- UI: `gov-docs/v3-ui.html`
- D1 기존 `docs_v2`, `docs_v2_members`, `docs_v2_events` 사용
- 기존 BREVO_API_KEY, HASA_API_KEY, SESSION_SECRET, DB 바인딩 유지

## Google Workspace / Notion 관리자 기능과의 격차
- 현재는 문서 소유자 관리자 기능만 구현
- 미구현: 조직 전체 관리자 계정, 그룹·조직도, 팀 워크스페이스, 계정 정지 및 강제 로그아웃, SSO/SCIM, 그룹별 공유정책, 조직 전체 감사 검색, DLP, 보존·폐기 정책, 대규모 관리자 분석, 관리자 역할 위임, 세션 정책
- 초기 전역 관리자 계정은 사용자 지정 및 안전한 부트스트랩 없이 임의로 부여하지 않음
- 별도 R2 활성화 없으므로 원본 바이너리 파일 보존 미구현

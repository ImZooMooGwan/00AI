# 00AI DOCS 베타 편집 안정성 추가 개선 보고
일자: 2026-10-29

## 개발 및 운영 배포
- 기존 주소: https://docs.00ai.kr/
- Worker: 00ai-gov-docs
- 수정 파일: gov-docs/v3-ui.html, gov-docs/worker.js
- Cloudflare 배포 PUT: HTTP 200

## 구현
1. **동시수정 충돌 복구 UX**: 기존 서버 optimistic revision 체크에서 409 충돌 시, 사용자의 미반영 HTML 문서를 내려받을 수 있는 복구창 표시. 최신본 열기는 경고 후 명시적인 사용자 선택으로 수행. 서버가 강제로 덮어쓰는 동작은 만들지 않음.
2. **표 구조 편집 안전장치**: rowSpan/colSpan 병합 셀이 포함된 표에서는 행·열 삽입/삭제를 차단해 단순 행·열 인덱스 조작으로 표가 깨지는 문제를 예방. 기본 단순표 편집은 유지.
3. **읽기 전용 저장 보호**: 조회자 역할에서 직접 저장을 진행하지 않도록 기존 클라이언트 저장 함수 가드 보강 (서버 ACL은 계속 적용).

## 검수
- 정적 JS 구문 분석: PASS
- UI와 Worker 내장 HTML 일치: PASS
- 프런트 요소 참조 검증: PASS (누락 ID 없음)
- 충돌 백업 및 병합셀 차단 코드: PASS (코드 존재)
- Cloudflare Workers 배포: PASS (HTTP 200)

## 한계 및 출시 판정
- 실제 두 사용자 동시 편집 충돌의 브라우저 E2E는 미검증.
- Tiptap/ProseMirror 및 Yjs/CRDT 실시간 공동 편집은 미구현.
- 복잡한 HWP 표·셀 병합/분할을 완벽히 편집할 수 있는 수준은 아님.
- 실사용 행정자료·개인정보 업로드 전 보안시험, 백업/복구, 권한 검증을 수행할 것.
- 기존 OTP 인증, HASA, D1 바인딩은 유지하는 방식으로 배포.

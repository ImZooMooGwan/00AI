# 00AI DOCS 온나라형 문서편집 UI 개편·배포 검수 (2026-11-03)

## 요청사항
기존 단순 리본 UI를 제공된 온나라 문서관리카드 화면을 참고한 실제 웹서비스 편집 UI로 개편. 정적 이미지 생성이 아니라 HTML/CSS/JS 및 Cloudflare Worker 수정.

## 실제 구현
- 상단 공공업무용 블루 헤더와 00AI DOCS 문서관리카드 제목
- 문서카드, 문서처리, 처리 경로, 수신·공유지정, 임시저장, 미리보기, 본문저장, 인쇄 동작 연결
- 파일 / 편집 / 입력 / 서식 / 쪽 / 표 / 보기 / AI 메뉴와 글꼴·크기·서식 편집 툴바
- 문서 편집 용지 넓이·여백·회색 작업 공간·눈금자 스타일 개편
- 좌측 공무원 양식 바로가기, 서식참조 검색 팝업(기존 샘플 목록 사용), 공문 기본 머리말 생성
- 오른쪽 문서카드 정보, 상태, 역할, 버전, 문서 ID와 문서처리 경로 보기
- 인쇄 시 문서 용지를 중심으로 불필요한 웹 UI 숨기기
- 기존 저장/로그인/댓글/AI/접근제어/실시간협업 경로 유지

## 정확한 기능 범위 및 한계
- 온나라 전자결재, 실제 결재선 지정, 기관 문서번호 발급, 공식 문서 서식 저장소 연동은 하지 않음.
- 결재 관련 버튼은 00AI DOCS 내부 검토·상태 화면 또는 안내 화면으로 이동.
- 검색 서식은 서비스 내 제공하는 예시 템플릿이며 실제 기관 양식 검색 결과 아님.
- 폰트/기본 서식 조작은 기존 contenteditable 기반이고, 온나라/HWP 엔진과 원형 수준으로 동일하지 않음.
- 실시간 Tiptap/Yjs 편집은 기존 /realtime-app/에 별도 위치; 한글문서 변환·기관 서식 복원은 제한적.
- 공개 이미지/기관 로고 및 실제 문서정보를 무단으로 복제하거나 저장하지 않음.

## 검수
- GitHub gov-docs/v3-ui.html 코드 수정 완료
- GitHub gov-docs/worker.js에 동일 UI 내장 확인
- JS 정적 문법 PASS
- 프런트에서 참조하는 DOM ID 누락 없음
- 주요 업무 버튼/문서카드/처리경로/서식창 코드 존재
- Cloudflare Worker 업로드 성공
- Cloudflare Worker settings에서 BREVO_API_KEY, HASA_API_KEY, SESSION_SECRET, DB, DOC_ROOM 바인딩 유지 확인
- 실제 로그인 브라우저 클릭 테스트/시각 비교/키보드 접근성/한글문서 import 품질은 아직 미검증

## 베타 권고
공개 및 합성 자료로 온나라형 화면 흐름을 평가하고, 공식 기관 연동과 혼동할 수 있는 문구에 대한 사용자 테스트 및 보안검수를 거친 후 확대.

PC에서 AI 분석을 쓰려면 에이전트를 설치하세요. 브라우저 근거 추출은 설치 없이 사용할 수 있습니다.

↓Windows 자동 설치install-windows.ps1
  1. 01설치 파일 다운로드Python 3.10 이상이 설치된 Windows PC에서 위 버튼을 누릅니다.
  2. 02내려받은 설치 파일 실행파일 내용을 확인한 뒤 PowerShell로 실행합니다. 최초 1회 HASA 키를 입력합니다.
  3. 03자동 시작 등록키는 Windows DPAPI로 암호화되고, 로그인 시 로컬 실행기가 자동으로 시작됩니다.
  4. 04사이트 자동 연결이 화면에서 PC 에이전트를 선택하면 127.0.0.1:43120 연결을 자동 확인합니다.
  5. 05문서 실행·결과 저장문서를 선택해 실행하고 근거·SHA-256·HASA 분석이 포함된 Markdown 결과를 내려받습니다.
기관에서 허용한 설치 파일의 실행 명령powershell -ExecutionPolicy Bypass -File .\install-windows.ps1

중요 설치 파일은 관리자 권한 없이 현재 사용자 계정에만 등록됩니다. 기존 이용자는 최신 설치 파일을 다시 실행해야 이번 마스킹 개선이 적용됩니다. 이 사이트나 GitHub에는 API Key가 저장되지 않습니다.

HOW HARNESS WORKS

내 문서는 어디로 이동할까요?

웹 화면은 요청과 결과만 조정합니다. 원문을 처리할 위치를 고른 뒤, AI 분석을 켜면 요청과 파일명, 추출 근거를 외부 AI에 전달합니다.

01브라우저 로컬가벼운 검토 · 설치 없음
선택한 문서→브라우저 메모리→결과 다운로드
  • 원문과 해시는 현재 탭에서 처리
  • HASA 및 다른 서버 전송 0 B
  • 탭을 닫으면 메모리 작업 상태 종료
02PC 에이전트선택 문서 · HASA 선택 분석
웹→127.0.0.1→근거 추출→HASA
  • 원문 처리·SHA-256은 이 PC에서 수행
  • 요청·파일명·근거의 이메일·휴대전화·주민번호 패턴 마스킹
  • 키는 Windows DPAPI 암호화, 웹에는 미노출
Windows 자동 설치 ↓
03행정망 내부 서버기관 시스템 · 통제형 실행
업무 PC→HTTPS + Token→내부 실행기→HASA
  • 선택 원문은 지정한 내부 서버까지만 이동
  • 방화벽·접근 토큰·허용 Origin으로 실행기 접근 제한
  • HASA에는 요청·파일명·추출 근거 전달
외부 송신 원칙원본 전체 파일 제외요청·파일명·근거 전달키는 실행기에서 사용현재 자동 마스킹은 이메일·휴대전화·주민등록번호 패턴을 대상으로 합니다. 이름·주소 등 모든 개인정보를 탐지하지는 않습니다. 외부 AI 사용과 전송 내용은 기관의 반출 기준에 따라 확인하세요.

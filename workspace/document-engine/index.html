⚖ 법령 MCP 연동

기존에 구현된 MCP 서버가 브라우저 접근이 가능한 HTTPS 인터페이스를 제공할 때만 연결할 수 있습니다. 법제처 API 중복 호출은 하지 않습니다.

미설정 · 법령 기능은 연결 전까지 참고 초안 형태로 제공

MCP 서버가 stdio 전용이면 브라우저에서 직접 연결할 수 없습니다. 기존 MCP를 HTTPS로 노출하는 승인된 어댑터가 필요합니다. 요청·응답 스키마 확인 후 실제 법령 검색을 사용할 수 있습니다.
